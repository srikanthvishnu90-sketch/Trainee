## What the rubric does not score (read by hand, all 60 screenshots)

The rubric passes 30/30, but it is only as hard as its five lines. Problems found by reading the pages:

1. **No compare brief has a comparison table (7/7 compare briefs).** The $0 fake draft (fake_model.ts marketDraft) never writes `comparison`, so a "compare A and B" File is a summary list, not a side-by-side table. The table's layout is covered by the existing fixture (research-brief-browser.test.ts), not by these 30. This measures the fake model, not the product; it must be re-checked with the real model before the flags are on.
2. **Pay briefs carry no government figure (7/7 pay briefs).** The eval's brain call passes no SOC code, so BLS OEWS/OOH and USAJOBS are never read, and the brief says so under "Not found in a free source". The real brain must pass `soc` (and `cbsa`) for pay questions.
3. **Every brief has 2 sources, both from one stub site.** The eval world serves only one made-up host per task; every other free source (ATS boards, Wikipedia, Wikidata, GitHub, news, SEC) 404s, so those reach the brief only as gap lines. Real free sources were not reachable from the build sandbox, so their JSON shapes are tested against documented formats in fixtures (tests/architect/research-free-sources.test.ts), not live.
4. **Long source host names break mid-word at 390 px** ("r0167-entrylevelsoftwareengineerpayi.e2e.te / st"). No overflow (overflow-wrap:anywhere), but it reads badly. Real hosts are short; the stub hosts are not.
5. **Compare briefs repeat gap lines per company** (up to 5 lines: board and Wikipedia for each company, plus SEC). Readable, but long.
6. **The cover thesis has no citation marker.** Its numbers are checked against cited pages (R1), but the reader cannot see which source it rests on.
